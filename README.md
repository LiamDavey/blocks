# Blocks

A Sokoban terminal game made with [Ratatui].

![Demo](docs/demo.gif)

## Install

Requires [Nerd Fonts].

Install [Rust], then:

```sh
cargo install --git https://github.com/LiamDavey/blocks
```

[Ratatui]: https://ratatui.rs
[Nerd Fonts]: https://www.nerdfonts.com/
[Rust]: https://rustup.rs/

## Play

```sh
blocks
```

| Key              | Action                                          |
| ---------------- | ----------------------------------------------- |
| `Left` / `h`     | Move left.                                      |
| `Right` / `l`    | Move right.                                     |
| `Down` / `j`     | Move down.                                      |
| `Up` / `k`       | Move up.                                        |
| `r`              | Restart level.                                  |
| `q`              | Quit.                                           |
